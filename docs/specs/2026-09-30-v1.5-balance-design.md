# AI 텍스트 어드벤처 v1.5 — 난이도·표시·표현 개선

작성일: 2026-09-30 · 기준: v1.4 · 계기: 플레이 기록(노예사장, 좀비 전투에서 연속 실패 끝에 빈사)

## 버그

- 기록관이 좀비를 "인물"로 등록 → 체력이 없어 공격해도 쓰러뜨릴 수 없었음
  - 기록관 규칙: 적대적인 존재는 반드시 `new_enemies`
  - 코드 안전장치: 이곳의 인물을 공격하면 그 인물을 적(체력 3)으로 전환
  - 적에 `max_hp` 추가, 상태(멀쩡함 / 상처 입음 / 빈사)를 판정관·내레이터·화면에 표시

## 난이도

- 성공 확률 = `clamp(60 + (내 능력치 − 필요) × 10 + 보너스, 1, 99)` (이전 50 기준)
- 필요 능력치 기준을 캐릭터 능력치 범위(보통 2~5)에 맞춤: 쉬움 1~2, 보통 3~4, 어려움 5~6, 전문가 7~8, 초인적 10~15 (최대 15, 기본 4)
- 오기: 연속 실패 1회당 +10% (최대 +30%), 성공하면 초기화

## 능력치 변화 폭

- 일시적 상태 효과: 기록관이 묘사를 보고 `{name, effect: "str+2" 등 ±1~3, turns 1~5}` 기록. 한 턴 2개, 동시 4개, 같은 이름은 덮어씀. 판정에는 효과를 더한 능력치 사용, 매 턴 1씩 줄어듦
- 영구 변화 예시 확대(각성, 결심, 트라우마 등)

## 표시·표현

- 주사위: 모든 테마에 기준 병기 — `주사위 66 → 실패 (1 이하가 나와야 성공)`, 코드 테마 `// need <= 1`
- 세부: 상태 효과(`내 힘 7 (아드레날린 +2)`), 오기(`오기 +20%`)
- 판정 이유: 이야기 속 상황으로. 능력치·성격·직업 이름이나 "~이 필요합니다" 금지
- 불가능 문구: 받침에 맞는 조사 자동(`josa`), 자연스러운 문장 (`레이저총을 가지고 있지 않다`, `은빛 열쇠는 여기에 없다`)
- 세상에 없는 물건 줍기(예: "주머니를 채운다") → 불가능 대신 "뒤져보기" 판정. 찾으려는 행동이 성공하면 찾은 물건은 획득
- 상태창 "이곳에 있는 것": 적(상태), 인물, 물건(클릭하면 "○○을 줍는다" 입력)
- 시작 화면 팁: 결과 대신 행동을 쓰면 확률이 높다
