# AI 텍스트 어드벤처 v1.2 — 묘사 검수 단계

작성일: 2026-09-29 · 기준: v1.1

## 목적

이름 검사로 못 잡는 "의미" 착각을 줄인다.

| 종류 | 예시 |
|---|---|
| 판정과 다른 묘사 | 실패했는데 성공처럼 씀 |
| 없었던 과거를 지어냄 | 싸운 적 없는 적과 싸운 것처럼 씀 |
| 이전 묘사와 모순 | 부서진 문이 다시 멀쩡함 |

## 흐름 (묘사·에필로그 공통)

1. 묘사를 스트리밍으로 출력 (기존과 동일)
2. 검수
   - 이름 검사(`unknownNames`)에 걸리면 → 그 내용을 문제로 삼음 (AI 검수 생략)
   - 아니면 AI 검수 호출: `{ consistent: boolean, problem: string }` (온도 0.1)
   - 검수 호출이 실패하면 통과로 간주 (게임을 막지 않음)
3. 문제가 있으면 **1회만** 다시 쓰기: 원래 메시지 + `assistant: 첫 묘사` + `user: 위 묘사에 문제가 있습니다: {문제}. 판정 결과와 사실에 맞게 처음부터 다시 쓰세요.` → `{type:'replace', target, text, reason}` 이벤트로 교체. 다시 쓴 묘사는 재검수하지 않음 (시간 제한)
4. 묘사가 대체 문장(코드 생성)이면 검수 생략

## 검수 입력 (확정 사실)

- 묘사: 판정 결과, 플레이어 입력, 현재 상황(`sceneFacts`), 쓰러뜨린 적, 지난 사건 기록, 직전 묘사 2개
- 에필로그: 엔딩, 최종 사실(마지막 장소·목표 아이템·보스), 지난 사건 기록

검수 규칙: 문체·분위기는 평가하지 않음. 모순 예시(판정 뒤집기, 없던 사건, 없는 소지품, 다른 장소, 쓰러진 적이 움직임)를 명시. 사실에 없는 사소한 분위기 묘사(바람, 냄새, 소리)는 모순이 아님.

## 화면

교체 시 묘사 아래에 작은 안내: `✎ 검수: {문제} — 다시 썼습니다`

## 비용

검수는 짧은 JSON 응답이라 턴당 +1~2초 예상, 다시 쓸 때만 +7~10초.

## 코드 변경

- `prompts.js`: `CHECK_SCHEMA`, `narrationFacts(state, input, result)`, `epilogueFacts(state)`, `checkMessages(facts, text)`. 에필로그의 최종 사실 목록은 `finalFacts(state)`로 분리해 공유
- `game.js`: `review()` 추가, `streamText`가 검수·재작성 담당
- `public/app.js`, `style.css`: 교체 안내 표시

## 테스트

- prompts: 사실 목록에 판정·쓰러뜨린 적·직전 묘사 포함, 에필로그 사실, 검수 메시지에 묘사 포함
- game: 모순 → 피드백 포함 재작성·reason 포함 교체 / 일관 → 유지 / 검수 오류 → 유지 / 이름 검사 걸리면 AI 검수 생략 / 대체 문장이면 검수 생략
- 수동: 실제 모델로 검수 시간 측정, 의도적으로 모순된 묘사를 넣어 검수가 잡는지 확인
