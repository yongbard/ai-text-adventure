# AI 텍스트 어드벤처 v1.3 — 필요 능력치 판정, 나비효과, 상태창 확장

작성일: 2026-09-30 · 기준: v1.2

## 배경 (플레이 피드백)

1. 주사위 결과(`35% → 주사위 48 (35 이하 성공)`)가 직관적이지 않음
2. "채팅을 시작한다"가 성공해도 아무도 나오지 않음 → 새 인물 등장 금지 규칙이 창의적 행동을 막음
3. 성격이 행동 종류 단위라 무관한 행동에 붙음 (고소공포증이 "기타 행동" 전체에 -5%)
4. 검수 오탐지 (도입부 사실을 모순으로 판단) + 검수 안내 문구 노출 불필요
5. 소지품·지식의 출처, 지난 기록을 볼 수 있으면 좋겠음
6. 자유도 최대화: 행동이 세계에 흔적을 남기고 나중에 불어나서 돌아오는 나비효과

## A. 확률 = 필요 능력치 vs 내 능력치

- 판정관이 `required`(1~20)를 정함: 이 캐릭터(직업·배경 기준)가 해내는 데 필요한 능력치. 쉬움 2~3, 보통 5, 어려움 7~8, 전문가 10~12, 초인적 15~20. 직업·특기에 맞으면 크게 낮추고 모르는 분야면 크게 높임. 플레이어 실제 수치는 고려하지 않음.
- `성공 확률 = clamp(50 + (내 능력치 − 필요) × 10 + 아이템(0~20) + 성격, 1, 99)`
- `base_chance` 폐지. 결과에 `required`, `statValue`, `critMax`, `fumbleFrom`, `traitsApplied` 포함.

## B. 성격: 상시 효과 + 관련 있을 때만 판정 보정

- 성격 데이터에서 행동별 보정(`action`)과 `vs_enemy` 제거, 대신 `check`(5~15): 관련 상황 판정 크기.
- 상시 효과는 유지: 능력치, 최대 체력, 대성공·대실패 범위, 받는/주는 피해, 회복량.
- 판정관이 플레이어 성격 중 이 행동과 **직접 관련된 것만** `traits: [{name, effect: help|hinder}]`로 표시 → 코드가 `±check` 적용.
- 밸런스 검증: 좋은 성격 `상시 점수 + check > 0`, 나쁜 성격 `상시 점수 − check < 0`.
- 이전 저장의 성격은 id로 새 정의로 교체.

## C. 나비효과 (씨앗 시스템)

요구: 오래 묵은 씨앗이 엔딩에 돌아옴(새끼 늑대 → 결전의 도우미), 사소한 행동도 씨앗(버튼 → 몇 턴 뒤 위기), **선악과 무관한 예측 불가 결과**(악행 → 깡패들의 왕), 그래도 줄거리는 목표로 수렴(깡패 군단으로 연구소 탈환 → 백신, 결말 색깔은 그림자).

### 씨앗

- 기록관이 "나중에 되돌아올 수 있는 행동"을 씨앗으로 등록 (돕기, 해치기, 누르기, 부수기, 약속, 거짓말, 훔치기 등 — 사소해도 포함). 턴당 3, 심어진 것 최대 12.
- 심는 순간 코드 RNG가 비밀로 정함:
  - 운명: 은혜 35% / 재앙 35% / 반전 30% (행동의 선악과 무관, 반전 = 기대와 정반대)
  - 때: 70%는 3~10턴 뒤 무작위, 30%는 최종 결전용(목표 장소에 들어서면 한꺼번에)
- 반전의 구체화: 기록관이 씨앗마다 `intent`(good/bad/neutral)를 기록. 반전은 코드가 방향(`twistAs`)을 정함 — 선의 → 해(bane), 악의 → 도움(boon), 중립 → 동전 던지기. (플레이 검증에서 모델이 "반전"을 스스로 만들지 못해 추가)
- 운명별 지시는 "반드시 이번 장면에서 눈에 보이는 이득/분명한 불이익"처럼 구체적으로. 검수는 지시와 반대 방향이면 모순으로 판단
- 발동(턴마다 하나): 목표 장소에 있으면 결전용 전부 → 아니면 때가 된 것 중 가장 오래된 하나 → 정체 3턴이면 가장 가까운 것을 앞당김 → 씨앗이 없으면 "새로운 사건" 지시
- 내레이터 지시: 씨앗이 {운명} 쪽으로 돌아옴, 이 결과가 최종 목표로 가는 길을 어떻게 바꾸는지 연결, 목표 자체를 바꾸거나 없애지 말 것
- 기록관이 발동 결과를 한 문장으로 기록(`seed_outcomes`), 은혜로 생긴 인물은 동료(`ally`)
- 화면: 실타래 탭에는 행동만 보이고 운명·때는 엔딩에서 공개. 턴 결과에 운명 정보는 저장·전송하지 않음

### 동료

- 동료 수 × 10% (최대 30%)를 목표 장소에서의 모든 판정에 더함. 에필로그에 반드시 등장.

### 결말 색깔

- 승리·사망·시간 초과는 코드가 판정 (뼈대 유지)
- 엔딩 시 짧은 AI 호출로 `{ tone: light|gray|shadow, title }` 결정 (행동 기록·씨앗 운명·동료 기반) → 에필로그가 그 색깔로 작성, 씨앗들이 어떻게 되었는지 공개
- 표시 예: `🏆 승리 — 그림자의 결말`

### 새로 생길 수 있는 것 (기록관이 등록)

| 종류 | 턴당 | 전체 | 규칙 |
|---|---|---|---|
| 씨앗 | 3 | 심어진 것 12 | 위 참고 |
| 지식 | 3 | - | 단서·사실·들은 이야기 |
| 인물 | 2 | 이야기 인물 10 | 이곳(`here`) 또는 원격. 대화 가능 |
| 물건 | 2 | 이야기 물건 15 | `obtained`이고 판정 성공이면 소지품, 아니면 이곳에 놓임. 회복 없음 |
| 장소 | 1 | 이야기 장소 6 | 현재 장소와 양방향 연결 (들어가지는 않음) |
| 적 | 1 | 이야기 적 6 | 체력 1~3, 이곳에 배치 |

- 이미 있는 이름은 무시. 보스·목표 아이템·열쇠는 기존 시나리오 것만 (새로 만든 물건은 잠긴 통로를 열지 못함).
- 기록관: 최종 묘사 후 JSON 호출(온도 0.2). 엔딩 턴에는 생략. 실패 시 무시.
- 현재 장소 설명이 비어 있으면 기록관이 채움.

### 탐험 (`explore`)

- 지도에 없는 곳으로 가기. 대상이 기존 장소 이름이면 `move`와 동일하게 처리(잠김 우회 불가).
- 성공 시 코드가 새 장소 생성·연결·이동 (설명은 비워 두고 기록관이 채움). 이야기 장소 6개 초과 시 불가능.

### 정체

새 장소 방문, 소지품·지식 증가, 기록관 등록이 하나도 없으면 +1, 있으면 0.

### 내레이터 규칙 변경

- "목록에 없는 것 등장 금지" → "행동으로 그럴듯하게 생겨나거나 드러나는 인물·물건·장소·상황은 등장 가능. 구체적으로 묘사해 이후 이어지게. 보스·목표 아이템은 현재 상황에 없으면 등장 금지, 열쇠나 목표를 대신하는 물건 금지."
- 심어진 씨앗(행동만), 알게 된 인물·동료 목록을 컨텍스트로 제공.

## D. 검수

- 안내 문구 화면 표시 제거 (조용히 교체).
- 검수 사실에 도입부 포함. 새로 등장하는 것, 실패·성공 원인의 설명 방식은 모순 아님. 판정 뒤집기와 사실 목록 정면 충돌만.

## E. 출처 추적

- 소지품 `acquired: {turn, input, how}` (시작 소지품 turn 0 "시작 소지품", 주움 "주움", 이야기 획득 "이야기 중 획득")
- 지식·씨앗·인물: 생긴 턴과 입력. 시나리오 NPC와 대화 성공 시 그 NPC의 정보를 지식으로 자동 기록. 같은 장소에 있게 되면 NPC "만남" 기록.
- 장소 첫 방문 턴, 기록(history)에 턴 번호.

## F. 화면

- 주사위: 난이도 라벨·성공 확률 제목, 확률 막대(대성공/성공/실패/대실패 구간) 위를 마커가 굴러가다 멈춤, 결과, 세부(`필요 지능 5 · 내 지능 4 · 아이템 +10% · 달변가 +15%`). 이전 버전 결과는 기존 문장 표시.
- 나비효과 줄 `🦋 나비효과 — 3턴의 "…"`, 턴 끝 세계 변화 줄 `🌱 … · 🧑 … · 🎒 …`
- 엔딩: 결말 색깔·제목, 씨앗별 운명과 결과 공개
- 상태창 탭: 상태 / 소지품·지식 / 인물·실타래 / 기록. 새 항목 시 탭 알림 점. 호버 툴팁으로 출처·설명, 기록 클릭 시 해당 턴으로 스크롤.

## 저장 호환

`migrateState`로 누락 필드 채움 (씨앗·지식 빈 목록, 성격 새 정의 교체, 기록 턴 번호 등). 이전 결과는 화면에서 기존 문장으로 표시.

## 작업 순서 (각 단계 TDD, 커밋)

1. traits: 상시 효과 + check, `traitBonus`, `describeTrait`
2. rules: required 판정, 성격 관련 보정, 동료 보정, 구간 정보, explore, 출처, 지식 자동 기록, `pickBlooms`, `applyChronicle`(씨앗 운명·때 추첨), `updateStagnation`, `migrateState`, `sanitizeResult`, publicState 확장
3. prompts: 판정관(required·traits·explore), 내레이터(자유도·나비효과·씨앗), 검수 완화, 기록관, 결말 색깔, 에필로그(씨앗 공개)
4. game: 발동 선택, 기록관 호출·적용, world 이벤트, 정체, 결말 색깔, 불러오기 마이그레이션
5. 화면: 탭·툴팁·기록, 확률 막대, 나비효과·세계 변화 줄, 검수 문구 제거
6. 실제 모델 검증
