# AI 텍스트 어드벤처 v1.4 — 테마 (라이트 / 위장 모드) · 보스 키

작성일: 2026-09-30 · 기준: v1.3 · 범위: 화면(public/)만. 서버·규칙 변경 없음

## 테마

| 테마 | 모습 |
|---|---|
| 다크 (기본) | 기존 화면 |
| 라이트 | 같은 구성, 밝은 색 |
| 코드 에디터 위장 | 좌측 액티비티 바 + 탐색기(상태창 탭이 `status.ts` / `inventory.ts` / `people.ts` / `history.log`), 가운데 편집기(줄 번호, 행동은 코드 한 줄, 판정은 `check(...)` 코드, 묘사는 주석 색), 하단 입력은 터미널, 상태바(`Ln {턴}`, 체력은 ⚠ 개수로) |
| AI 코딩 도우미 위장 | 좌측 대화 목록, 가운데 채팅(행동 = 사용자 메시지, 판정 = `● Roll(...) ⎿ ...` 도구 호출 블록, 묘사 = 답변), 우측 컨텍스트 패널, 하단 메시지 입력창. 특정 제품의 로고·이름은 쓰지 않음 |

- 시작 화면(직업 입력 아래)에서 선택, 즉시 미리 적용. `localStorage`에 기억(실패해도 동작).
- 위장 테마에서는 이모지·주사위 애니메이션·체력 반짝임 끔. 확률 막대는 코드 에디터에선 얇게, AI 도우미에선 숨김.
- 게임 제목은 위장 테마에서 숨기고 파일 탭(`story.ts`) 또는 대화 제목으로 대체.

## 보스 키

- 어느 테마에서든 **Esc** → 전체 화면을 가짜 업무 화면으로 덮음, 다시 Esc → 복귀 (입력 중이던 내용 유지).
- 코드 에디터·다크·라이트: 가짜 TypeScript 파일. AI 도우미: 가짜 코딩 대화.

## 구현

- `index.html`: 테마 선택 버튼, 위장용 장식 요소(상단 메뉴, 액티비티 바, 대화 목록, 상태바), 보스 화면. 제목 옆 아이콘은 `.ic`로 감싸 위장 테마에서 숨김.
- `style.css`: 색은 변수로, `[data-theme]`별 재정의와 배치(grid 순서) 변경.
- `app.js`: 테마별 문구 포맷터(`FMT`), 아이콘 헬퍼 `ic()`, 탭 이름·입력 안내 문구 교체, 보스 키.
